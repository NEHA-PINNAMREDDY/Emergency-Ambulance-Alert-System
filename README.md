 🚑 Emergency Ambulance Alert System

 📌 Project Overview

The **Emergency Ambulance Alert System** is a smart traffic management solution designed to reduce ambulance response time during emergencies. The system tracks the live location of an ambulance, calculates the shortest route, and assists in clearing traffic by providing route visualization on an interactive map.

The project aims to improve emergency medical services by enabling faster ambulance movement through congested roads using real-time location tracking and route optimization.

---

 ✨ Features

* 🚑 Real-time ambulance location tracking
* 🗺️ Interactive map visualization using Leaflet
* 📍 Shortest path calculation
* 📡 GPS-based location updates
* 🌐 Web-based dashboard
* 📊 Live route monitoring
* 🚦 Traffic-aware emergency response concept
* 💻 User-friendly interface

 ⚙️ Installation

 1. Clone the Repository

```bash
git clone https://github.com/your-username/Emergency-Ambulance-Alert-System.git
```

 2. Navigate to the Project Folder

```bash
cd Emergency-Ambulance-Alert-System
```

 3. Install Python Dependencies

```bash
pip install flask
pip install flask-cors
pip install requests
```

 4. Run the Flask Server

```bash
python app.py
```

 5. Open the Dashboard

Open the `index.html` file in your browser or run the Node.js server if configured.
